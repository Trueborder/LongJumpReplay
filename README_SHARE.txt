LONG JUMP REPLAY 2.3

1. Extract the complete ZIP folder.
2. Run LongJumpReplay.exe.
3. Use Start Competition Wizard, or open Settings for a judge-only setup.
4. Space toggles Freeze / Live. Returning Live can store the attempt as Not decided and advance automatically.
5. Left/Right step individual frames. ShuttleXpress is supported.

No Python installation is required.
Do not run the EXE directly from inside the ZIP.
