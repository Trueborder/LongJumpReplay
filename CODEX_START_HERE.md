# Codex start here

1. Read `PROJECT.KNOWLEDGE.md`.
2. Codex automatically sees `AGENTS.md`; it points to the same source of truth.
3. Follow `docs/development/WINDOWS_CODEX_SETUP.md` for setup and transfer.
4. Run `SETUP_DEVELOPMENT.ps1`.
5. Start Codex with `START_CODEX.ps1`.
6. Paste the onboarding prompt from `CODEX_FIRST_PROMPT.md`.

Do not begin a large feature until the current tests pass and the repository has an initial Git commit.
