# Recommended system requirements / Doporučené systémové požadavky

## English

- Windows 11, 64-bit
- Recent Intel Core i5 / AMD Ryzen 5 processor or better
- 16 GB RAM
- SSD with at least 10 GB free space
- Full HD (1920 × 1080) display
- USB 3 camera capable of 1280 × 720 at 60 FPS; 120 FPS is recommended for detailed review
- Stable USB connection for the camera and, when used, Contour ShuttleXpress
- Mains power and Windows sleep disabled during an event

The packaged application does not require Python. Running from source requires Python 3.12 x64. Always test the complete computer, camera, cable, lighting, and selected recording mode before an event.

## Česky

- Windows 11, 64bitový
- Novější procesor Intel Core i5 / AMD Ryzen 5 nebo výkonnější
- 16 GB RAM
- SSD s alespoň 10 GB volného místa
- Full HD monitor (1920 × 1080)
- USB 3 kamera podporující 1280 × 720 při 60 FPS; pro detailní kontrolu doporučujeme 120 FPS
- Stabilní USB připojení kamery a případně ovladače Contour ShuttleXpress
- Napájení ze sítě a vypnuté uspávání Windows během závodu

Zabalená aplikace Python nevyžaduje. Spuštění ze zdrojových kódů vyžaduje Python 3.12 x64. Před závodem vždy otestujte celou sestavu: počítač, kameru, kabel, osvětlení a zvolený režim záznamu.
