# Current backlog and ideas

This is a planning list, not a promise. Preserve the current stable workflow before adding scope.

## High value

- Real Windows profiling of Quiet/Balanced/High/Evidence presets.
- Camera capability scanner with device names and tested mode combinations.
- Physical ShuttleXpress validation and setup wizard.
- Better session recovery and Windows crash simulation tests.
- Split `main_window.py` into domain controllers.

## Competition management

- CSV athlete import/export.
- Optional athlete names while retaining simple numeric mode.
- Optional manual distance entry.
- Automatic top-N finalist selection from entered distances.
- Event templates and reusable competition presets.

## Operator quality

- One-click diagnostic report for camera/FPS/drop/cache state.
- Better first-run onboarding.
- Optional secondary observer display over local network, only after core stability.
- Accessibility pass for high contrast, keyboard navigation, and color-blind-safe palettes.

## Explicitly out of current scope

- Automatic Valid/Foul decision.
- Official measurement of jump distance.
- Multiple synchronized cameras.
- Cloud accounts or mandatory online services.
