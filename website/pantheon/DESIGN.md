# Pantheon — name as a monument

## Direction

On this page, Pantheon's name and block-built temple become a typographic monument and a panoramic world plate. The name's architectural reference carries the composition; Minecraft's server-address ritual supplies its useful live interaction. Chosen from Taste Skill's three dealt directions because the oversized name fits Pantheon's temple identity without adding stock fantasy ornament.

## Visual system

Warm stone paper, charcoal ink, and a single moss-green action accent follow the dealt Three Stones palette. Self-hosted Chivo variable type is the primary family. Keep tracking at or above -0.04em. Use generous but purposeful spacing, large wordmark type, small readable body text, square-to-soft rectangular controls, flat fields, and no card-grid template, gradients, resting shadows, pill badges, ornamental numbers, or eyebrow headings.

The wordmark spans most of the first viewport width. A short factual description and a copyable address share the surrounding space; the illustration becomes a deliberate panorama rather than a dark background for text. Saturated color belongs primarily to the artwork. Feature routes use uneven editorial pacing within a coherent grid. The final wordmark closes the page in inverse colors.

## Interaction and accessibility

The same Chivo, temple mark, stone surfaces and moss controls extend to the wiki (reading) and player account (operations). Layouts follow each surface's purpose. Shared semantic colors retain danger, warning, token, success and information meanings in both themes. Light / Dark / System controls use a common runtime and a parent-domain preference cookie so the choice follows visitors across Pantheon sites. The default follows the operating system.

Keep the existing copy button, selection fallback, language anchors, mobile navigation, native disclosures, and live-status semantics. Never imply the illustrated scene is an actual server view. Quiet 160–240ms feedback is limited to interactions; live refresh and keyboard actions remain immediate. Reduced motion disables entrance effects. At narrow widths the name remains readable, the primary action stays reachable, and no columns overflow.
