PRIVACY / LONGJUMPREPLAY TRIAL

Trial registration privacy.

The optional free evaluation requires an email address before the 72-hour trial starts. The address is stored with the trial registration, a hashed machine identifier, trial dates, export limit, and consent choices.

Why this data is used

The email is used for trial support, licensing communication, and—only when separately selected—product updates. The machine identifier prevents repeated trial registration on the same computer. Trial data is not sold.

Retention and choices

Trial records are retained only as long as needed for support, licensing administration, abuse prevention, and legal obligations. Marketing consent is separate and can be withdrawn by contacting info@tomaspisar.cz.

Technical operation

The application receives a signed trial token from the trial service. Trusted time is obtained from WorldTimeAPI when available; the application continues from its last trusted local deadline when offline. The desktop application does not send usage telemetry.
