DOWNLOAD & WINDOWS NOTICE

Your browser or Windows may show a warning.

LongJumpReplay is independent Windows software. Chrome, Edge or Microsoft Defender SmartScreen may treat a new installer as uncommon before it has built reputation. If you used the official button above and the file is named LJR_setup.exe, it is safe to keep and run.

If the download is blocked

Open the browser's Downloads panel and choose Keep or Download anyway. Confirm that the source is files.tomaspisar.cz.

If Windows blocks setup

In the SmartScreen window choose More info, verify LJR_setup.exe, then choose Run anyway to continue installation.

WHAT TO DO NOW

Getting started

Do this on the computer you want to use LongJumpReplay on. You will need an internet connection for the activation itself.

  1. Download and install

    Use the download button above, then run the installer. Windows SmartScreen may show a warning for a new publisher; review the file and continue.

  2. Enter your purchase email

    Start LongJumpReplay. In the activation window, enter the same email address you just used at checkout. A verification code is sent to it.

  3. Enter the code

    Type the verification code into the application. This computer is then activated and you can start using LongJumpReplay.

No verification code after a few minutes? Check your spam folder first. If it is not there, write to info@tomaspisar.cz and we will sort it out.
