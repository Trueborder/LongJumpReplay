TP / ABOUT

About me.

I’m Tomáš Pisár, an independent student developer from the Czech Republic. I build focused software for real situations, with a particular interest in desktop applications, sports technology, and video workflows.

01 / APPROACH

Useful over loud.

My work starts with a practical problem, not a list of fashionable features. I look at how a decision is made, what slows the operator down, and where software can make the next action clearer.

I prefer small, deliberate tools that do one job well. That means reducing unnecessary steps, keeping important information visible, and designing for the conditions in which the product will actually be used.

02 / FOCUS

What I work on

Four connected areas shape the projects I build and the way I evaluate them.

01

Desktop software

Focused Windows applications designed around a real operator and a clearly defined task. I care about predictable controls, readable states, and tools that remain responsive during everyday work.

02

Sports technology

Sport combines speed, precision, and pressure. I’m interested in software that supports officials and operators without getting between them and the decision they need to make.

03

Video and replay

A useful replay is more than a video player. It must preserve the right moment, make precise review easy, and keep the surrounding workflow moving.

04

Interface design

Good interfaces make the current state and next action obvious. I aim for clear hierarchy, useful feedback, and visual detail that supports the task instead of competing with it.

03 / PROCESS

From observation to a working tool

The details become clearer when a project is tested against the real workflow early and often.

  1. Understand the situation

    Map the people, equipment, constraints, and decisions involved before choosing a technical solution.

  2. Build the essential path

    Make the core workflow usable first, so every new feature has a clear reason to exist.

  3. Test and refine

    Use realistic scenarios to find friction, improve reliability, and simplify the controls before release.

04 / CURRENT WORK

LongJumpReplay

LongJumpReplay is the first product presented here. It is a Windows application for reviewing long-jump take-offs with live video replay while capture continues in the background.

The project brings together the themes above: a specific sporting decision, a time-sensitive operator workflow, precise video review, and an interface that keeps the important action close at hand.
