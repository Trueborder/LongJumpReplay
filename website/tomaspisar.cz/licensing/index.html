01 / WHAT YOU BUY

What a license includes

One payment, one Windows computer, no expiry. The price is shown on the product page.

  • One-time purchaseNot a subscription. You pay once and the license stays valid; there is no recurring charge and nothing to renew.
  • One Windows computerThe key authorises a single computer. A second station, such as a spare competition laptop, needs a second license.
  • No expiry dateThe key carries no expiry and is never checked against a server, so it cannot stop working because a date passed or a service went down.
  • Works without internetActivation and everyday use are both fully offline. A competition venue with no connectivity is not a problem.
  • Windows installerThe same installer as the free trial. Installing it does not require a license; the key is what unlocks unlimited exports.
  • Email supportWrite to me about installation, activation, or a problem during a competition. Replacement keys after a hardware change are free.

02 / ACTIVATION

How activation works

Five steps. The one people do not expect is step three: I need the machine code from your computer before I can issue the key.

  1. Pay through Stripe

    Payment is handled entirely by Stripe. Stripe emails you a receipt straight away. The license key is not in that email.

  2. Install and start the app

    Download the Windows installer and run LongJumpReplay. On first launch it shows the activation window.

  3. Send me your machine code

    The activation window shows a machine code in the form 9622-9BB8-F5FC-3CB9. Email it to info@tomaspisar.cz from the address you paid with.

  4. I send back your key

    I generate a key bound to that machine code and reply with it. Normally the same day, at the latest within two working days.

  5. Paste it in and use it

    Paste the key into the License key field and confirm. That is the last time an internet connection is involved in licensing.

Use an email address you can actually read. It is how I send the key and how I reach you about a replacement later. It is not an account and it is never entered into the application.

04 / BEFORE YOU BUY

Good to know first

The limitations, stated plainly. You should not discover any of these after paying.

  • The key does not arrive automaticallyDelivery is not instant. I issue each key by hand after you send me your machine code, so expect a short wait rather than an immediate download.
  • Hardware changes can break activationThe machine code is derived partly from your computer name and network adapter. Renaming the PC, swapping a network card, or sometimes a docking station can change it, and the key then stops matching.
  • Replacement keys are freeIf activation breaks after a hardware change or you move to a new computer, email me the new machine code and I reissue at no cost. It is manual, so it is not instant.
  • One license, one stationIf you run two runways at once, or keep a backup laptop ready at a meet, you need a license for each. Write to me about more than one and we will sort it out.
  • Windows onlyThere is no macOS or Linux build. The trial is the safest way to confirm it runs on the machine you intend to use.
  • Try before you buyThe free 72-hour trial is the whole application with up to three exports. It needs no email, no account and no internet. Use it to check your camera and computer first.

06 / QUESTIONS

Frequent questions

If your question is not here, write to me and I will answer it - and add it to this list.

I have paid. What happens now?

Stripe emails you a payment receipt immediately, but the license key is not in it. Install LongJumpReplay, start it, copy the machine code from the activation window, and email that code to info@tomaspisar.cz. I generate the key and send it back to the same address.

I normally reply the same day, at the latest within two working days. If you have heard nothing by then, write again - an email has gone astray somewhere.

What email address should I use?

Use an address you can actually read, and preferably the same one you paid with, because that is how I match your request to your payment. It is how I send your key and how I reach you later about a replacement.

The email address is not an account and it is never typed into the application. Knowing an address is not what activates the software - the key bound to your machine code is.

Can I use one license on two computers?

No. One key authorises one computer, because the machine code of that computer is written into the key itself. A spare laptop, or a second runway running at the same time, needs a second license.

Two computers on one license is planned but not built. If you need several stations, write to me first and we will work something out.

What if I buy a new computer?

You keep your license. Install LongJumpReplay on the new computer, email me the machine code it shows, and I issue a replacement key free of charge. There is nothing to deactivate on the old machine.

Because it goes through me, it is not instant. If you are switching computers before a competition, ask a few days ahead rather than the morning of the meet.

Does LongJumpReplay need an internet connection?

No. Not to install, not to activate, and not to run. The key is checked mathematically on your own computer, so the application never contacts a server about your license.

You need a connection twice, and only for people rather than for software: to pay, and to exchange emails with me about your key.

Will it stop working at a venue with no internet?

No. Once the key is entered, an activated copy works offline indefinitely. There is no periodic check to fail and no grace period to run out, because there is no online verification at all.

Activate at home or in the office before you travel, though - not because the software needs it, but because getting the key from me requires email.

What happens if I reinstall Windows?

It depends on whether the machine code comes out the same. It is calculated from the operating system, the computer name and the network adapter identifier, so if you reinstall Windows on the same hardware and give the computer the same name, your existing key usually still works.

If the name differs, the key will not match. Send me the new machine code and I issue a replacement free of charge.

My key stopped working. Why?

Almost always because the machine code changed. Renaming the computer, replacing or disabling a network card, and sometimes plugging in a docking station or USB network adapter can all change it, and the key then no longer matches.

Nothing has been revoked and your license is intact. Email me the machine code now shown in the activation window and I send a new key free of charge.

Can I transfer my license to someone else?

Write to me. Since every key is bound to a machine code and issued by hand, a transfer means issuing a key for the new owner's computer, which I am happy to do for a club handing equipment to a new coach.

Do I get updates, and for how long?

Your license is perpetual and the version you install keeps working indefinitely. Nothing expires and nothing switches off.

I do not currently sell a fixed updates period, and I am not going to promise one I have not defined. Updates within version 3 are provided, and if a future major version ever changes that, I will say so here in advance.

How is my payment handled?

Payments are processed entirely by Stripe. Your card details go directly to Stripe and I never see your card number. From Stripe I receive your name, email address, billing country and the amount paid, which I keep as accounting records.

Can I try it before buying?

Yes, and I would recommend it. The installer includes a free 72-hour trial with up to three successful exports. It is the complete application, not a cut-down demo, and it needs no email address, no account and no internet connection.

Use it to confirm your camera, your capture hardware and your computer all work together before you spend anything.

Still unsure?

Ask before you buy rather than after. I answer licensing questions myself.
