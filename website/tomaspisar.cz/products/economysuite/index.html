Players reach connected systems from /menu, with shared balances, progression, and inventory-safe flows.

MONEY / MARKET

Earn and trade

Balances, player payments, jobs, buy and sell shops, auctions, player orders, trades, and a mailbox for returned items.

QUESTS / REWARDS

Keep progressing

Daily and weekly tasks, profession chapters, achievements, login streaks, timed challenges, leaderboards, and unlockable titles.

WORLD / IDENTITY

Player homes and warps, server rules, private messages, cosmetics, chat prefixes, colors, scoreboard, and TAB list.

SERVER OWNER VIEW

Configure the rules of your world.

A server toolkit should be manageable after installation. EconomySuite keeps its systems configurable and its persisted game data in SQLite.

CONFIGURATION

Change behavior in-game or in files.

Tune prices, rewards, tasks, jobs, crates, messages, and more through YAML configuration. Admins can use the chest-based /economy config editor and apply supported changes with /economy reload.

  • Player statistics and crate wins can be exported as readable files.
  • Vault economy integration; Essentials is not required.

GET STARTED

Install with your server in mind.

Back up first, preserve plugin data when updating, and keep Vault installed. The Pantheon guide covers the player-facing systems.

  1. Check the Paper, Java, and Vault requirements.
  2. Stop the server and create a backup before replacing the plugin JAR.
  3. Restart the server, review plugins/EconomySuite configuration, and check command permissions.
